---
name: ERP 전송 품번 가드 적용 범위
description: 임시 품번이 UNIERP로 넘어가지 않게 막는 검사를 어느 경로에 모두 걸어야 하는지
---

화성 간소화 폼은 품번을 모르면 기종명이나 '미정'을 임시 품번으로 저장합니다. ERP 품목 마스터에 없는 품번은 승인되거나 ERP로 전송되면 안 됩니다.

**Why:** 승인 경로와 RPA 조회 경로가 여러 개입니다. 한 곳에만 검사를 넣으면 다른 경로로 우회됩니다. 실제 사내 RPA(rpa-ncr)는 설정상 API가 아니라 DB를 직접 조회합니다(source=db). 그래서 API의 pending 조회 엔드포인트에만 검사를 넣으면 실제 전송은 막히지 않습니다. 수산톡 "승인" 버튼 콜백도 웹 승인과 별도의 경로입니다.

**How to apply:** 승인·전송 규칙을 바꿀 때는 웹 상태 변경 API, 수산톡 버튼 웹훅, RPA 트리거 API, API pending 조회, rpa-ncr DB 조회를 모두 함께 수정합니다. api-server의 공용 품번 가드 헬퍼를 재사용합니다.
