---
name: SSO 접근 정책
description: DX Dashboard Hub 연동에서 유지할 NCR 계정 허용 목록과 역할 경계
---

SSO는 기존 NCR 활성 계정에만 연결합니다. 자동 가입이나 중앙 ADMIN 역할을 통한 NCR 관리자 승격은 하지 않습니다. 첫 연결은 확인된 유일한 이메일로, 이후에는 중앙의 고유 식별자로 연결합니다.

**Why:** 기존 주소록 등록 대상과 사용자가 이미 부여한 NCR 권한을 중앙 인증 연동이 확대하거나 덮어쓰지 않도록 하기 위한 결정입니다.

**How to apply:** SSO 제공자나 사용자 동기화를 변경할 때도 계정 허용 목록과 NCR 역할을 별도로 검증합니다. 기존 그룹웨어·내부 로그인은 유지하므로 전체 접근을 차단하려면 NCR 계정도 비활성화해야 합니다.

OIDC 자동 검색을 도입하기 전에는 공개 메타데이터의 issuer와 모든 엔드포인트가 중앙 운영 도메인을 가리키는지 확인합니다.

**Why:** 중앙 운영 도메인에서 메타데이터를 조회해도 개발용 replit.dev 주소가 반환되는 것을 관찰했습니다. 메타데이터의 존재만으로 운영용 OIDC 설정이 올바르다고 판단할 수 없습니다.

**How to apply:** 자동 검색으로 전환하기 전 실제 응답을 다시 조회하고 운영 주소와 대조합니다. 현재 안내받은 운영 엔드포인트를 메타데이터의 개발 주소로 자동 교체하지 않습니다.
