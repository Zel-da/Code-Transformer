## 하루 사용 순서

1. **UNIERP 켜고 로그인** → 부적합등록(S) 폼 한 번 열어둠
2. **바탕화면 `NCR RPA` 더블클릭** → 콘솔 뜨고 브라우저 자동 열림 (`127.0.0.1:8010`)
3. 대시보드에서:
   - **[PENDING 조회]** → 큐 채움
   - **[ERP 창 확인]** → "메인 창 찾음"
   - **[입력 시작]** → 자리 비우고 대기
4. **검토 패널** 뜨면 각 보고 확인 → **[완료 확인]** 또는 **[모두 확인]**

## 절대 지킬 것

<blockquote class="warn">
[!warn] <strong>RPA 도는 중 마우스·키보드 금지</strong>. 다른 창 클릭·채팅·메일 확인 X.
포커스 이탈 감지되면 자동 중지되고 <span class="tag tag-failed">FAILED</span> 마킹.
</blockquote>

## 새로 알아둘 것 (2026-07 반영)

### T1 — 갇힌 보고 자동회수
- 이전엔 RPA 크래시하면 보고가 <span class="tag tag-processing">PROCESSING</span> 로 갇혀 손으로 DB 열어야 했음
- **이제 5시간 지나면 자동 <span class="tag tag-pending">PENDING</span> 로 복원** → 다음 조회에서 다시 처리
- 아무것도 안 해도 됨. 로그에서 `[auto-recovered]` 표시 확인 가능

### T2 — REVIEW 상태
- 이전 배치 검토 큐는 서버 재시작하면 사라짐 → **UNIERP 이중입력 위험** 있었음
- 이제 UNIERP 저장 직후 DB 에 <span class="tag tag-review">REVIEW</span> 로 기록
- **브라우저 닫아도, 콘솔 닫아도, PC 재부팅해도** 검토 대기 그대로 남음
- 다시 대시보드 열면 자동으로 **이전 세션 REVIEW 보고들이 복원됨**

### T3 — 동기화 4회/일
- ERP 신규 자재/거래처가 앱에 반영되기까지 최대 12h → **약 5h** 로 단축
- 하루 4회: 05:00 / 10:00 / 12:30 / 17:00

## 자주 겪는 상황

| 상황 | 대응 |
|---|---|
| UNIERP 창 못 찾음 | 창 켜져 있는지 확인. 최소화도 안 됨. `[ERP 창 확인]` 재클릭 |
| 로그인 창에서 멈춤 | 비밀번호 확인. 대시보드 ③번 섹션에서 설정 |
| 필드 좌표 어긋남 | ⑧번 좌표 편집 UI 에서 조정 (`/api/field-mapping`) |
| 도중에 잘못됨 | 즉시 **[중지]** → 처리 중 보고는 자동 PENDING 복원 |
| 여러 보고 REVIEW 로 쌓임 | 검토 패널에서 하나씩 UNIERP 화면 대조 → 확인 |
| 서버 재시작 후 REVIEW 남음 | 대시보드 다시 열면 자동 복원됨. 확인만 하면 됨 |

## 종료

- **콘솔 창을 닫으면 서버 종료**
- 검토 안 끝난 REVIEW 는 DB 에 그대로 남음 (다음에 이어서 확인)
- 브라우저만 닫으면 서버는 계속 실행 중 (콘솔 살아있으면)
