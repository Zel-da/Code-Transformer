RPA 설치 가이드

NCR(부적합 보고) → UNIERP 자동 입력 워커 — 백승기 직장님 PC 설치용

A. 설치할 프로그램

아래 순서대로 설치합니다.

#프로그램용도다운로드
1 Git for Windows 레포 클론 + 업데이트 git-scm.com/download/win
2 Python 3.11 또는 3.12필수 RPA 실행 환경 python.org/downloads/windows
설치 시 ✅ "Add Python to PATH" 체크 필수
3 UNIERP 자동 입력 대상 (이미 설치돼 있을 것) —
4 VS Code (선택) 설정 파일 편집·로그 확인 편함 code.visualstudio.com
주의: Python 3.13 버전은 psycopg2-binary 휠이 아직 안 올라와 설치 실패할 수 있습니다. 반드시 3.11 또는 3.12 사용하세요.

B. 설치 절차 (3단계 — 명령어 입력 없음)

1ZIP 파일 풀기

USB로 받은 rpa-ncr_for_install.zip 을 원하는 위치에 압축 해제. 권장 위치:

C:\Users\<직장님계정>\Documents\rpa-ncr\

2DB 접속정보 파일 복사 (USB에서)

USB에 들어있는 app_db.json 파일을 다음 경로에 복사:

rpa-ncr\PRIVATE\app_db.json
보안: app_db.json 은 USB로 직접 복사만 하세요. 메일·메신저·클라우드 업로드 금지.

3시작.bat 더블클릭

압축 푼 폴더에 시작.bat 파일을 더블클릭하면 끝.

첫 실행 시 자동으로 처리하는 것:
  1. Python 설치 여부 검사
  2. 가상환경 자동 생성 (.venv 폴더)
  3. 필요한 패키지 11개 자동 설치 (인터넷 필요, 약 2~3분)
  4. 설치 완료 시 자동으로 웹 대시보드 실행
2회차부터는 설치 단계를 건너뛰고 바로 실행됩니다 (몇 초 내).

(선택) 바탕화면 바로가기 만들기

매번 폴더 들어가기 귀찮으면 바탕화면에 바로가기 만들기.bat 을 한 번 더블클릭 → 바탕화면에 "NCR RPA" 아이콘 생성. 이후로는 바탕화면 아이콘만 클릭하면 됩니다.

ERP 환경값 조정 (선택)

직장님 PC의 UNIERP 경로·비밀번호가 다르면 대시보드의 "ERP 설정" 섹션에서 바로 수정 가능. 직접 파일을 편집하려면 config\settings.json:

키설명
erp.launch_path 직장님 PC의 UNIERP 바로가기 실제 경로
예: C:/Users/<계정>/OneDrive/Desktop/UNIERP/UNIERP.appref-ms
erp.login_pw 직장님 ERP 비밀번호 (비워두면 본인이 직접 로그인)

C. 첫 실행 + 캘리브레이션

1프로그램 실행

시작.bat 더블클릭. 첫 실행이면 자동 설치 진행 후 브라우저가 http://127.0.0.1:8010 으로 자동 오픈됩니다.

2캘리브레이션 ★중요

왜 필요? field_mapping.json의 좌표는 본인 PC(2576×1408) 기준으로 잡혀 있고, 창 크기에 맞춰 자동 비례 변환되지만 — 직장님 PC 해상도가 다르면 첫 1건은 반드시 사람이 지켜보면서 확인해야 합니다.
  1. UNIERP 로그인 → 부적합등록(S) 폼을 한 번 직접 열어둔다
  2. 대시보드에서 "PENDING 조회" → 1건만 "입력 시작"
  3. 17개 필드 들어가는 위치가 어긋나면 → field_mapping.json의 ref_x/ref_y 미세 조정
  4. 대시보드 검토 패널에서 어긋난 항목만 "재실행" → 다 맞으면 "완료 확인" 클릭해서 서버에 완료 통보

3정상 동작 확인되면 일상 운영

  • 수동 일괄: 대시보드 "PENDING 조회" → "입력 시작"
  • 자동 폴링: python run_worker.py --poll (주기적으로 PENDING 자동 처리)

D. 가져갈 것 체크리스트

  • USB — PRIVATE/app_db.json 복사용
  • 본인 노트북 — 직장님 PC에서 인터넷 안 될 때 venv 통째로 복사할 수 있게
  • 직장님 ERP 계정·비밀번호 미리 확인
  • 직장님 PC 해상도 미리 확인 (FHD/QHD/4K?)

E. 자주 발생할 문제

증상원인 / 조치
psycopg2-binary 설치 실패 Python 3.13 사용 중. → Python 3.11 또는 3.12 재설치
입력 위치가 1~2 필드 어긋남 해상도 차이. field_mapping.json ref_x/ref_y 미세 조정
입력 위치가 완전히 다른 곳 UNIERP 창이 최대화 안 됨 / 다른 폼이 떠 있음. 부적합등록(S) 폼을 먼저 띄울 것
"부적합등록(S)" 메뉴 안 보임 직장님 ERP 계정에 메뉴 권한 없음. IT/관리자에게 권한 요청
"DB 연결 실패" PRIVATE/app_db.json 파일 누락/오타. 경로·JSON 형식 확인
다른 창 클릭하면 즉시 멈춤 정상 동작 (포커스 이탈 보호). RPA 도는 동안 다른 작업 자제
