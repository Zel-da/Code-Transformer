현장에서 <strong>부적합(NCR)을 발견하면 이 순서대로</strong> 등록하세요. 자세한 설명·예외는
<a href="작업자_상세.html">상세 가이드</a>에.
</div>

## 3단계로 끝

1. **모바일/PC 브라우저**에서 NCR 앱 접속 → 로그인
2. **[신규 등록]** → 부품/호기 검색해서 **ERP 자동채움** → 사진·설명 추가
3. **[저장]** → 끝. QC 담당자에게 자동 알림 감

## 반드시 채우는 것 (필수)

| 항목 | 설명 |
|---|---|
| 부품코드 | 검색으로 찾음. 없으면 담당자에게 문의 |
| 공정 | 발생 공정 (자동 목록) |
| 상세 설명 | 어떤 부적합인지 짧게라도 |
| 조치방향 | 등록 시점 선택 (기본값 있음) |

## 편하게 만드는 팁 3개

- **부품코드 대신 제품명 검색**: `T-380N` 처럼 모델명으로 검색 가능
- **호기로 검색**: `345` 처럼 호기 번호만 넣어도 부품·거래처 자동 매칭
- **거래처만으로 검색**: `리파츠` 같은 거래처명으로도 관련 부품 찾음

## 검색이 안 될 때

<blockquote class="warn">
[!warn] 방금 ERP 에 등록된 신규 자재는 <strong>최대 5시간</strong> 지나야 앱에서 검색됩니다
(하루 4회 자동 동기화: 05:00 / 10:00 / 12:30 / 17:00).
급하면 담당자에게 알려주세요. 우선 <strong>부품코드를 수동 입력</strong>하고 나머지 필드는 비워도 저장됩니다.
</blockquote>

## 사진 첨부

- 부적합 부위를 사진으로 찍어 첨부 (모바일 카메라 바로 사용 가능)
- 자동으로 크기 압축돼 업로드 (원본 크기 걱정 X)
- 여러 장 필요하면 상세 설명에 언급

## 자주 헷갈리는 것

| 항목 | 어떻게 |
|---|---|
| 호기 (제조호기) vs 출하호기 | **같은 호기 필드**. RPA 가 알아서 구분 |
| 거래처 못 찾음 | 비워두고 저장. QC 담당자가 나중에 채움 |
| 잘못 저장했음 | **삭제 불가**. QC 담당자에게 코멘트로 알림 |
| 두 번 눌러서 두 번 등록됨 | 저장 버튼은 **1회만 눌러도 잠김** — 걱정 X |

## 저장 후

- 자동으로 **QC 담당자에게 알림**
- 사용자는 **목록에서 상태 추적** 가능
- 상태 <span class="tag tag-completed">COMPLETED</span> 로 바뀌면 UNIERP 반영 끝
