## 1. 접속과 로그인

- 브라우저(**모바일 크롬/사파리, PC 크롬**)에서 회사에서 안내한 앱 주소로 접속
- 처음이라면 담당자에게 **계정** 요청
- 로그인하면 **본인 이름·소속 공장이 자동 프로필** 로 설정됨

## 2. 신규 부적합 등록 화면

### 2.1 상단 필수 필드

| 필드 | 필수 | 설명 |
|---|:-:|---|
| **양산/개발** | ✓ | 기본값 "양산". 개발품이면 변경 |
| **등록자** | ✓ | 로그인 이름 자동 |
| **공장** | ✓ | 프로필의 소속 공장 자동 (아산/화성). 다를 때만 변경 |
| **공정** | ✓ | 공장에 맞는 공정 목록에서 선택 |
| **발생일** | | 기본값 오늘. 어제 발견이면 변경 |
| **불량수량** | | 개수 (숫자) |

### 2.2 부품/제품 검색 — 핵심 편의 기능

부품코드 필드 옆의 **[검색]** 을 누르면 여러 방식으로 찾을 수 있습니다:

| 검색 조합 | 결과 |
|---|---|
| **부품코드** (예: `T8NH-0000000-00`) | 정확 일치, 단건 자동채움 |
| **부품코드 + 호기** (예: `+ 345`) | 정확 일치 + 해당 호기 거래처까지 자동 |
| **제품명** (예: `T-380N`) | 부분 일치 후보 목록 |
| **제품명 + 호기** (예: `T-380N + 345`) | 후보 좁혀서 단건 자동 |
| **호기만** (예: `345`) | 이 호기로 생산·출하된 부품 후보 |
| **거래처명** (예: `리파츠`) | 이 거래처가 납품한 부품 후보 |

<blockquote class="info">
[!info] <strong>한자·로마 숫자 자동 변환</strong>: <code>JD-1400EⅡ</code> 로 검색해도
<code>JD-1400EII</code> 로 등록된 부품이 매칭됩니다.
</blockquote>

**자동채움되는 값** (한 번의 검색으로 다 채워짐):
- 부품코드
- 제품명 / 모델명
- 품목그룹
- 공장 / 공장코드
- 출하호기 (해당하면)
- 거래처 (해당하면)

### 2.3 검색이 안 되는 3가지 경우

1. **방금 ERP 에 등록된 신규 자재**
   → 앱은 하루 4회(05:00 / 10:00 / 12:30 / 17:00) 동기화. 최대 5시간 대기.
   → 급하면 부품코드만 수동 입력하고 저장. QC 담당자가 나머지 채움.

2. **후보가 25건 넘게 뜸**
   → 호기 번호를 함께 넣어 좁힘. 아니면 스크롤로 골라 선택.

3. **거래처가 자동 매칭 안 됨**
   → 이 부품·호기 조합의 출하 이력이 아직 없는 경우. 비워두고 저장 가능.

### 2.4 사진 첨부

- **[사진 첨부]** 클릭 → 모바일: 카메라 or 갤러리 / PC: 파일 선택
- 자동 압축 (약 500px 기준, 원본 크기 걱정 X)
- 여러 장이면 상세 설명에 "사진 3장 참조" 라고 명시

### 2.5 상세 설명

- 부적합이 **어떻게, 어디에서 발생했는지** 짧게라도 기록
- QC 담당자·RPA 가 이 내용을 참고
- 자유 텍스트 (개행 가능)

### 2.6 조치방향

- 등록 시점에 선택 (기본값 있음, 필요 시 변경)
- QC 담당자가 나중에 변경 가능

## 3. 저장

- **[저장]** 을 누르면:
  - 서버가 자동으로 부적합 번호(예: `QC-2607-0001`) 발급
  - 상태 <span class="tag tag-pending">PENDING</span> 로 등록
  - QC 담당자에게 슈산톡/이메일 알림 자동 발송
- **버튼 이중 클릭 방지**: 저장 중에는 버튼이 잠기고 잠깐 후에 폼이 초기화됨

## 4. 등록 후 상태 추적

**목록** 페이지에서 본인이 등록한 보고 확인 가능:

| 상태 | 뜻 |
|---|---|
| <span class="tag tag-pending">PENDING</span> | 등록 완료, RPA 대기 중 |
| <span class="tag tag-processing">PROCESSING</span> | RPA 가 UNIERP 에 입력 중 |
| <span class="tag tag-review">REVIEW</span> | UNIERP 저장 완료, RPA 운영자 확인 대기 |
| <span class="tag tag-completed">COMPLETED</span> | 최종 확인 완료. 종결 |
| <span class="tag tag-failed">FAILED</span> | 실패. RPA 운영자에게 문의 |

## 5. 자주 하는 질문

**Q. 잘못 저장했어요. 삭제 가능?**
A. 삭제 API 는 관리자만 가능. **QC 담당자에게 코멘트로 요청**하거나, 새 보고를 다시 등록하고 이전 보고에 "취소 요청" 코멘트를 남기세요.

**Q. 여러 부품이 동시에 부적합이면?**
A. 각 부품별로 별개 보고. 부적합 번호가 각각 발급됩니다.

**Q. 오프라인에서 등록 가능?**
A. 아니오. 네트워크 필요. 오프라인 발생 시 사진만 미리 찍어두고 나중에 등록.

**Q. 로그인 안 됨.**
A. 회사 담당자에게 계정 활성화 확인 요청. 비밀번호 초기화는 IT 관리자.

**Q. 부품코드 검색이 완전 안 됨.**
A. 서버 문제일 수 있음. 우선 **부품코드만 수동 입력해서 저장**하고 IT 관리자에게 알림.

## 6. 언제 누구에게 문의?

| 상황 | 문의 대상 |
|---|---|
| 신규 자재가 ERP 에 없음 | 자재 담당자 |
| 자동 검색 안 됨 | IT/관리자 |
| 등록 실패, 저장 안 됨 | IT/관리자 |
| 보고 내용 수정·삭제 | QC 담당자 |
| UNIERP 반영 안 됨 (<span class="tag tag-completed">COMPLETED</span> 안 됨) | RPA 운영자 |
