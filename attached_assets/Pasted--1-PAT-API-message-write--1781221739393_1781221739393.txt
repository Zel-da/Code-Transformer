🔑 1단계: PAT 토큰 발급
수산톡 관리자 계정으로 로그인 → 설정 → API 토큰 메뉴에서 발급합니다.

스코프: message:write 선택 (관리자만 발급 가능)
발급 직후 표시되는 sst_xxx... 문자열을 안전하게 보관 (다시 조회 불가)
📡 2단계: API 호출 방법
기본 URL: https://수산톡-배포-도메인/api/external/v1/messages
인증: 모든 요청에 Authorization: Bearer sst_YOUR_TOKEN 헤더 포함
Content-Type: application/json

📨 전송 모드 3가지
① 단건 DM — 특정 직원에게 1:1 메시지
수신자를 3가지 방법 중 하나로 지정합니다.

방법 A — 이메일로 지정 (가장 간단)

curl -X POST https://YOUR_DOMAIN/api/external/v1/messages \
  -H "Authorization: Bearer sst_YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "toEmail": "gildong.hong@soosan.co.kr",
    "content": "📋 결재 요청이 도착했습니다. 확인 부탁드립니다.",
    "botName": "전자결재 봇",
    "roomName": "✍️ 전자결재 알림"
  }'

방법 B — 사원번호로 지정

curl -X POST https://YOUR_DOMAIN/api/external/v1/messages \
  -H "Authorization: Bearer sst_YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "toEmployeeId": "IMP00123",
    "content": "💰 이번 달 급여 명세서가 등록되었습니다.",
    "botName": "급여 시스템"
  }'

방법 C — 이름 + 부서 조합

curl -X POST https://YOUR_DOMAIN/api/external/v1/messages \
  -H "Authorization: Bearer sst_YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "toName": "홍길동",
    "toDept": "수산인더스트리 > 개발팀",
    "content": "🔔 오늘 오후 2시 회의실 예약 확인하세요.",
    "botName": "회의실 봇"
  }'

성공 응답:

{ "ok": true, "messageId": 123, "roomId": 45 }

② 다수 수신자 — 여러 명에게 동시에
recipients 배열로 최대 100명까지 한 번에 전송합니다. 성공/실패가 개별로 반환됩니다.

curl -X POST https://YOUR_DOMAIN/api/external/v1/messages \
  -H "Authorization: Bearer sst_YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "recipients": [
      { "toEmail": "user1@soosan.co.kr" },
      { "toEmployeeId": "IMP00456" },
      { "toName": "김수산", "toDept": "수산세보틱스 > 영업팀" }
    ],
    "content": "🎉 연말 행사 안내: 12월 20일 오후 6시, 본사 대강당",
    "botName": "HR 봇",
    "roomName": "📢 HR 공지"
  }'

응답 (일부 성공, 일부 실패 혼합 가능):

{
  "ok": true,
  "sent": [
    { "userId": 11, "email": "user1@soosan.co.kr", "name": "홍길동", "messageId": 50, "roomId": 23 },
    { "userId": 42, "email": "user2@soosan.co.kr", "name": "김수산", "messageId": 51, "roomId": 24 }
  ],
  "failed": [
    { "spec": { "toEmployeeId": "IMP00456" }, "error": "사용자를 찾을 수 없음" }
  ]
}

③ 채널 공지 — 기존 채널 전체에 메시지
채널 이름으로 지정하면 봇이 해당 채널 멤버 전원에게 메시지를 게시합니다.

curl -X POST https://YOUR_DOMAIN/api/external/v1/messages \
  -H "Authorization: Bearer sst_YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "channelName": "전사 공지",
    "content": "🚨 오늘 오후 6시부터 서버 점검이 있습니다. 저장하지 않은 작업을 미리 저장해두세요.",
    "botName": "IT 운영 봇"
  }'

사용 가능한 채널 이름 예시:

전사 공지 — 전 직원 (2,500+명)
수산인더스트리 전체
수산아이앤티 전체
수산세보틱스 전체
수산홈텍 전체
수산이앤에스 전체
성공 응답:

{ "ok": true, "messageId": 53, "roomId": 6, "channel": "전사 공지" }

⚙️ 공통 파라미터 정리
파라미터	필수	기본값	설명
content	✅	—	메시지 본문 (최대 4,000자)
botName	❌	수산톡 시스템	봇 표시명. 값마다 별도 봇 계정 자동 생성
roomName	❌	🔔 알림	DM 채널 표시명 (단건/다수 수신자 모드만)
contentType	❌	text	text 또는 system
botName 팁: 시스템별로 다른 이름을 쓰면 수신자 입장에서 어떤 시스템에서 온 메시지인지 구분할 수 있습니다. 예: ERP 봇, 급여 시스템, 전자결재 봇

📋 전송 이력 조회
# 최근 전송 이력 (기본: 성공만)
curl https://YOUR_DOMAIN/api/external/v1/messages \
  -H "Authorization: Bearer sst_YOUR_TOKEN"
# 실패 포함 이력 조회
curl "https://YOUR_DOMAIN/api/external/v1/messages?includeFailures=true&limit=50" \
  -H "Authorization: Bearer sst_YOUR_TOKEN"

🐍 Python 예시 코드
import requests
TOKEN = "sst_YOUR_TOKEN"
BASE_URL = "https://YOUR_DOMAIN/api/external/v1"
def send_bot_message(to_email: str, content: str, bot_name: str = "ERP 봇"):
    resp = requests.post(
        f"{BASE_URL}/messages",
        headers={"Authorization": f"Bearer {TOKEN}"},
        json={
            "toEmail": to_email,
            "content": content,
            "botName": bot_name,
            "roomName": "🏢 ERP 알림",
        },
        timeout=10,
    )
    resp.raise_for_status()
    return resp.json()
# 사용 예
result = send_bot_message(
    "gildong.hong@soosan.co.kr",
    "📦 발주 승인이 완료되었습니다. 발주번호: PO-2026-001234"
)
print(f"전송 완료: messageId={result['messageId']}")

❌ 주요 오류 코드
HTTP	원인	해결
401	토큰 없음 또는 만료	토큰 재발급
403	message:write 스코프 없음	관리자에게 올바른 스코프로 재발급 요청
404	수신자/채널 없음	이메일·사원번호·채널명 확인
400	수신자 지정 안 됨, content 없음, 100명 초과	요청 본문 확인
