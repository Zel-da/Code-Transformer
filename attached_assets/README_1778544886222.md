## 사용 예 (모바일 앱 개발)

1. 앱 시작 시 01~04 다운로드 → 로컬 캐시
2. 사용자가 부적합 작성:
   - 불량유형 → 01_flaw_type.csv 에서 선택
   - 공정 → 02_flaw_process.csv 의 PLANT_CD/PROCESS_CD 선택
   - 처분 → 03_disposition.csv
   - 발행팀 → 08_dept_master.csv (또는 07 의 자주 쓰는 부서 우선)
3. 등록 후 → ERP `Q_FLAW_CKO063` 에 INSERT
