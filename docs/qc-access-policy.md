# QC 화면·API 접근 정책

| 기능 | admin | reviewer | approver | worker | collaborator |
| --- | --- | --- | --- | --- | --- |
| 관리대장 목록·보고서 일반 조회 | 허용 | 허용 | 허용 | 허용 | 허용 |
| `/qc`, `/qc/:reportId` | 허용 | 허용 | 허용 | 관리대장으로 이동 | 관리대장으로 이동 |
| QC 분석 저장·조치·검토 단계 삭제 | 허용 | 허용 | 허용 | 403 | 403 |
| QC 상태 전이 | 기존 전이표 적용 | 기존 전이표 적용 | 기존 전이표 적용 | 403 | 403 |
| 협업·댓글용 `/api/users/directory` | 허용 | 허용 | 허용 | 허용 | 허용 |
| 계정 관리 `/api/users` | 허용 | 403 | 403 | 403 | 403 |

- 로그인하지 않았다면 QC 직접 URL은 로그인으로 이동하고 원래 경로를 보존한다.
  로그인 완료 후에도 QC 역할 검사를 거친다.
- 새로고침에서는 `/api/auth/me` 확인이 끝나기 전 QC 화면을 렌더링하지 않는다.
  로컬에 저장된 사용자 역할만으로 접근을 허용하지 않는다.
- API는 매 요청마다 현재 활성 계정의 역할을 확인한다. 오래된 토큰의 관리자 역할로
  QC 분석 저장, 조치, 상태 변경, 삭제를 우회할 수 없다.
- 최종 승인(`RESOLVED → APPROVED`)은 기존대로 approver만 허용한다.
  QC 화면 접근 권한이 모든 상태 전이를 허용한다는 의미는 아니다.
- 일반 조회 API와 일반 보고서 수정 정책은 변경하지 않는다. QC 필드는 일반 수정 API의
  허용 필드에 포함되지 않으며 상태 변경은 전용 API를 사용한다.
- `/api/users/directory`는 활성 사용자의 id·아이디·표시 이름·역할·활성 여부만 반환한다.
  협업 대상 선택과 댓글 멘션을 위해 로그인 사용자에게 제공한다. 이메일, 부서 설정,
  임시 비밀번호 여부 등 계정 관리 정보는 포함하지 않는다.
- QC 저장 API의 403은 권한 오류로 표시하고 현재 계정 정보를 다시 확인한다.
  일반 보고서 수정의 7일 SLA 오류로 잘못 안내하지 않는다.

## 회귀 확인

서버 회귀 테스트: `pnpm --filter @workspace/api-server exec vitest run tests/qc-access.test.ts`

DB와 알림 발송을 대체하여 실제 인증·역할 미들웨어와 경로 처리기를 검증한다.
다섯 역할의 일반 조회, QC 역할의 저장, worker·collaborator의 QC 쓰기 우회 거부,
익명·비활성 계정, 오래된 권한 토큰, 최종 승인 제한, 디렉터리의 반환 필드,
관리자 사용자 API의 접근 제한을 포함한다.

브라우저에서는 다섯 역할 각각으로 `/qc`와 `/qc/:reportId`에 직접 접속하고
새로고침한다. QC 역할만 목록·상세를 볼 수 있어야 하며 나머지는 관리대장으로
이동해야 한다. 관리대장·댓글·QC 상세에서 `/api/users` 요청이 없어야 하며,
협업·멘션 목록은 `/api/users/directory`로 정상 로드되어야 한다.

### 브라우저 확인 결과 (2026-10-23)

- 다섯 역할 모두 QC 목록·상세의 직접 URL과 새로고침 시 위 역할 제한을 확인했다.
- worker·collaborator의 차단된 QC 화면에서는 하위 목록·상세 요청이 발생하지 않았다.
  일반 보고서 목록·상세 API는 두 역할 모두 정상 응답했다.
- worker의 일반 관리대장 상세 화면은 확인했다. collaborator의 상세 API는 확인했지만
  테스트 행을 찾는 브라우저 선택자가 시간 초과하여 해당 상세 패널의 UI 확인은 남았다.
- reviewer의 QC 저장은 화면 조작 후 새로고침·DB 재조회로 확인했다.
  admin·approver의 저장은 서버 회귀 테스트로 확인했으며 별도 UI 저장은 수행하지 않았다.
- 네 비관리자 역할의 계정 관리 목록 403과 최소 디렉터리의 정상 응답을 확인했다.
- 로그아웃 상태의 로그인 이동, worker 로그인 후 보존된 QC 경로 차단,
  worker 토큰과 위조된 로컬 관리자 프로필 조합의 새로고침 차단을 확인했다.
- 임시 테스트 계정·보고서·댓글·감사 기록은 정리했다. 외부 알림은 발송하지 않았다.
