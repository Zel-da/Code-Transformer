공정 부적합 등록 및 관리

일반 등록자를 위한 빠른 사용자 가이드

LOGIN

로그인 방법

일반 사용자

아이디: 회사 전체 이메일 주소
예: name@soosan.co.kr

비밀번호: 그룹웨어에서 사용하는 비밀번호

관리자

아이디: 관리자가 안내받은 관리자 아이디
예: admin

비밀번호: 관리자 계정의 내부 비밀번호

중요: CSV로 새로 등록된 일반 사용자는 회사 이메일과 그룹웨어 비밀번호로 로그인합니다. 이메일 주소는 반드시 전체 주소를 입력하세요.

SUBMIT

부적합 보고서 등록

1

부적합 등록 메뉴 선택

로그인 후 상단 또는 하단 메뉴에서 부적합 등록을 누릅니다.

2

기본 정보 입력

양산/개발, 등록자, 공장과 발생 공정을 확인하거나 선택합니다.

3

품목 선택

품목코드 또는 품목명으로 검색하고 올바른 품목을 선택합니다.

4

부적합 내용 작성

발생일, 불량 수량과 부적합 현상을 구체적으로 입력합니다.

5

사진 첨부

필요한 경우 현장 사진을 최대 5장까지 촬영하거나 선택합니다.

6

접수하기

내용을 다시 확인한 뒤 접수하기를 한 번 누르고 완료 화면이 표시될 때까지 기다립니다.

CHECK

등록 후 확인

  • 접수된 보고서는 관리대장에서 확인할 수 있습니다.
  • 검색창에서 품목명, 모델명 또는 보고서 번호로 찾을 수 있습니다.
  • 등록 후 수정이 필요하면 관리자 또는 QC 담당자에게 요청하세요.
  • 완료 화면이 나오기 전에 화면을 닫거나 접수 버튼을 반복해서 누르지 마세요.

추가 도움이 필요한가요?

시스템의 도움말 메뉴에서 상세 안내와 화면 투어를 확인할 수 있습니다.
