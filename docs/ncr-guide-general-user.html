01 · 로그인

회사 계정으로 로그인

NCR 시스템 주소를 열고 회사 이메일과 그룹웨어 비밀번호를 입력합니다.

아이디

회사 이메일 전체 주소
name@soosan.co.kr

비밀번호

그룹웨어에서 사용하는 현재 비밀번호

CSV로 새로 등록된 사용자도 동일합니다.
별도의 NCR 비밀번호를 발급받는 것이 아니라 회사 이메일과 그룹웨어 비밀번호로 로그인합니다.
  • 이메일은 앞부분만 입력하지 말고 @soosan.co.kr까지 입력하세요.
  • 로그인이 안 되면 먼저 그룹웨어에 같은 비밀번호로 로그인되는지 확인하세요.
  • 계정 없음 또는 비활성 안내가 나오면 NCR 관리자에게 문의하세요.
02 · 등록

부적합 보고서 등록

현장에서 부적합을 발견하면 가능한 한 바로 등록합니다. 상단 또는 모바일 하단의 부적합 등록 메뉴를 선택하세요.

1

생산 구분 확인

양산 또는 개발 중 해당 구분을 선택합니다.

2

등록자와 공장 확인

등록자명이 본인인지 확인하고 아산공장 또는 화성공장을 선택합니다.

3

발생 공정 선택

부적합이 실제로 발견된 공정을 선택합니다. 공장이 바뀌면 공정도 다시 선택해야 합니다.

4

품목 검색

품목코드 또는 품목명 일부를 입력하고 ERP 검색 결과에서 정확한 품목을 선택합니다. 선택 후 코드와 모델명을 확인하세요.

5

발생 정보 입력

발생일과 실제 불량 수량을 입력합니다. 수량을 모르면 확인 후 입력하고 임의 숫자를 넣지 마세요.

6

부적합 현상 작성

어디에서, 어떤 현상이, 어느 정도 발생했는지 담당자가 이해할 수 있도록 구체적으로 작성합니다.

7

사진 첨부 및 최종 확인

필요한 사진을 첨부하고 공장·공정·품목·수량·설명이 맞는지 확인합니다.

8

접수하기

접수하기를 한 번 누르고 완료 안내가 나올 때까지 기다립니다. 완료 후 보고서 번호를 확인합니다.

좋은 작성 예
“조립 3공정에서 실린더 브래킷 체결홀 위치가 도면 대비 약 4mm 편심된 제품 2EA 발견.”
03 · 사진

사진 첨부 요령

권장 사진

전체 위치를 알 수 있는 사진, 불량 부위를 가까이 찍은 사진, 치수나 라벨을 확인할 수 있는 사진

첨부 제한

최대 5장까지 첨부할 수 있으며 모바일에서는 카메라로 바로 촬영할 수 있습니다.

  • 흔들리거나 너무 어두운 사진은 다시 촬영하세요.
  • 불량 위치를 손가락이나 표시 도구로 가리키면 확인이 쉽습니다.
  • 사진 업로드 중에는 화면을 닫거나 접수 버튼을 반복해서 누르지 마세요.
04 · 조회

등록한 보고서 확인

관리대장 메뉴에서 보고서와 현재 처리 상태를 확인할 수 있습니다.

1

검색

품목명, 모델명 또는 NCR 보고서 번호를 검색창에 입력합니다.

2

필터

상태, 공장, 공정 필터를 함께 사용하면 필요한 보고서를 빠르게 찾을 수 있습니다.

3

상세 보기

목록에서 보고서를 선택해 접수 내용, 사진, QC 분석 결과와 댓글을 확인합니다.

수정이 필요할 때
일반 사용자는 접수 후 직접 수정할 수 없습니다. NCR 번호와 수정할 내용을 정리해 품질 관리자에게 요청하세요.
05 · 상태

처리 상태 이해하기

접수검토 중협업 대기조치 완료승인 완료ERP 등록
상태의미사용자가 할 일
접수보고서가 정상 등록됨내용과 NCR 번호 확인
검토 중품질 담당자가 검토 중추가 확인 요청에 응답
협업 대기관련 부서 확인 또는 조치 대기담당자로 지정됐다면 요청 내용 확인
조치 완료원인 분석과 조치 입력 완료필요 시 결과 확인
승인 완료품질 승인 완료최종 판정 확인
ERP 등록ERP 연동까지 완료별도 조치 없음
06 · 문제 해결

자주 묻는 질문

품목이 검색되지 않아요

공장을 먼저 선택하고 품목명 일부 또는 품목코드로 다시 검색하세요. ERP에 없는 품목이면 관리자에게 문의합니다.

공정이 보이지 않아요

선택한 공장이 맞는지 확인하세요. 그래도 없다면 공정 추가를 관리자에게 요청합니다.

접수 버튼이 작동하지 않아요

화면에 표시된 필수 입력 오류를 확인하고 네트워크 연결 후 다시 시도합니다. 반복 클릭은 피하세요.

중복으로 등록했어요

임의로 다시 수정하지 말고 중복된 NCR 번호를 품질 관리자에게 전달해 삭제를 요청하세요.

도움이 더 필요하면
시스템의 도움말 또는 투어 시작을 이용하고, 해결되지 않으면 화면 캡처와 NCR 번호를 함께 관리자에게 전달하세요.
